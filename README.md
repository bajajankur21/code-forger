# Code Forger Backend

This is the Spring Boot backend for the Code Forger multi-agent system.
It is deployed using Hugging Face Spaces with the Docker SDK.

## Configuration for Hugging Face
- **SDK:** Docker
- **Port:** 7860
- **User:** 1000 (Non-root)
- **RAM:** 16GB (CPU Basic)
